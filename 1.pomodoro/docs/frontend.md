## モジュール仕様（計画中）

### TimerEngine

残り時間の計算とタイマー制御を担う。

**主要な責務**:
- 開始・一時停止・リセット操作の制御
- 終了予定時刻（`endTime`）と現在時刻の差分で残り時間を算出（毎秒減算ではない）
- タブ非アクティブ時の時間ずれを抑える

**設計ポイント**: `setInterval` で毎秒 tick を発火するが、残り時間の計算は `endTime - Date.now()` の差分から行う。

### SessionFlow

作業・休憩セッションの遷移管理を担う。

**主要な責務**:
- 作業（25分）→ 短休憩（5分）→ 作業 のサイクル管理
- 4回作業完了ごとに長休憩（15〜30分）へ遷移
- サイクルカウント（`cycleCount`）の管理

**遷移ルール**:

```
作業完了
  cycleCount % 4 == 0 → 長休憩
  それ以外            → 短休憩

休憩完了 → 作業
```

### StatsStore

当日の統計データを localStorage に保存・復元する。

**主要な責務**:
- 当日の完了ポモドーロ数（`completedPomodoros`）の更新・保存
- 当日の累計集中秒数（`focusSecondsToday`）の更新・保存
- `todayKey`（YYYY-MM-DD）を使って日付切り替わり時に自動リセット
- ページ再読み込み後の状態復元

### UIRenderer

DOM 更新を一手に担う。

**主要な責務**:
- 残り時間テキストの更新（mm:ss 形式固定）
- 円形プログレスバーの描画更新（SVG または conic-gradient）
- 現在モード名の表示切り替え
- 開始/停止ボタンの状態切り替え
- 統計カード（完了数・集中時間）の表示更新

## UI コンポーネント（計画中）

| コンポーネント | 説明 |
|---|---|
| モード表示 | 「作業中」「短休憩」「長休憩」を切り替え表示 |
| 円形プログレスタイマー | SVG または conic-gradient で実装。中央に残り時間（mm:ss）を表示 |
| 開始/一時停止ボタン | 実行状態に応じてラベルとスタイルを切り替え |
| リセットボタン | 現在モードの初期時間へ戻す |
| 今日の進捗カード | 完了ポモドーロ数・当日集中時間を表示 |
