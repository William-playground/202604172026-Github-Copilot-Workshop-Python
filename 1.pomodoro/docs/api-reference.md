### 将来拡張（フェーズ7以降）

以下は設計ドキュメントに記載された将来追加予定の API。現時点では未実装。

#### GET /api/settings

ユーザー設定（作業時間・休憩時間など）を取得する。

#### POST /api/settings

ユーザー設定を更新する。

#### GET /api/stats/today

当日の統計情報（完了ポモドーロ数・集中時間）を取得する。

#### POST /api/stats/today

当日の統計情報を更新する。

#### GET /api/history

セッション履歴一覧を取得する。
