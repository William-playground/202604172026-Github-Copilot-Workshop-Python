# ポモドーロタイマー 実装機能一覧

## 1. 初期リリースで必要な機能（MVP）

- トップページ表示機能
- 単一ページで完結するタイマー画面表示
- 作業モードのカウントダウン（25:00開始）
- 開始機能
- 一時停止機能
- リセット機能（当該セッションの初期値へ戻す）
- 残り時間の毎秒表示更新（mm:ss固定）
- 円形プログレス表示の更新
- 実行中状態に応じたボタン状態切り替え（開始/停止など）
- モード表示（作業中・短休憩・長休憩）
- セッション終了判定
- 作業/短休憩/長休憩の自動遷移
- 4回作業完了ごとの長休憩ルール
- 当日完了ポモドーロ数の集計
- 当日集中時間（秒→時間表示）の集計
- 当日進捗カード表示（完了数・集中時間）
- localStorageへの当日統計保存
- ページ再読み込み時の状態復元（少なくとも当日統計）
- 日付切り替わり時の当日データリセット
- タブ非アクティブ時の時間ずれを抑える実装（終了時刻差分計算）
- モバイル幅でも崩れにくいレスポンシブUI

## 2. 初期リリースであると実用性が上がる機能（準必須）

- 実行中タイマーの復元（再読み込み後も継続計算）
- モードごとの配色切り替え
- セッション完了時の通知（画面内表示または音）
- 作業・休憩時間設定の保存（localStorage）

## 3. 将来拡張（後続フェーズ）

- 設定API（取得・更新）
- 日次統計API
- 履歴API
- SQLite永続化（統計・履歴・設定）
- 履歴一覧画面
- 分析画面（週次/月次の可視化）

## 4. ゲーミフィケーション（モチベーション維持施策）

モチベーション維持と継続利用の促進を目的に、以下の要素を段階的に追加する。初期版の保存先は localStorage とし、将来的には SQLite + API へ移行可能な構造とする。

- 経験値システム（XP/レベル）
  - 作業セッション完了で XP 加算
  - 長休憩到達（4 セット目完了）時のボーナス XP
  - レベル到達時のレベルアップ表示
- 達成バッジ（実績）
  - 『はじめの一歩』: 初回作業セッション完了
  - 『3 日連続』: 3 日連続で 1 ポモドーロ以上達成
  - 『週 10 回』: 同一週内に 10 回完了
  - 『集中 2 時間』: 1 日で累計 2 時間以上の集中時間達成
- ストリーク表示
  - 連続達成日数のカウントと表示
  - 日付が空いた時点で 1 にリセット
- 統計可視化
  - 週間・月間の完了回数／集中時間の簡易グラフ
  - 完了率、平均集中時間の表示
- 日次履歴の保持（localStorage に日付キー別で保存）

## 5. 実装順の推奨

1. 最小タイマー（表示、開始/停止/リセット、25分動作）
2. モード遷移（作業・短休憩・長休憩、4回ルール）
3. 当日統計（完了数・集中時間、UI反映）
4. localStorage復元（日次リセット含む）
5. 通知・設定・将来APIへの拡張
6. ゲーミフィケーション（XP/レベル、ストリーク、バッジ、週間・月間グラフ）
   - architecture.md ではフェーズ 5、plan.md ではフェーズ 8 に対応する（各ドキュメントのフェーズ粒度に従い番号は揃わない）
