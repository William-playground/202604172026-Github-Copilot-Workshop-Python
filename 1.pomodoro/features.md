# ポモドーロタイマー 実装機能一覧

## 1. 初期リリースで必要な機能（MVP）

- トップページ表示機能
- 単一ページで完結するタイマー画面表示
- 作業モードのカウントダウン（25:00開始）
- 開始機能
- 一時停止機能
- リセット機能（当該セッションの初期値へ戻す）
- 残り時間の毎秒表示更新（mm:ss固定）
- 円形プログレス表示の更新
- 実行中状態に応じたボタン状態切り替え（開始/停止など）
- モード表示（作業中・短休憩・長休憩）
- セッション終了判定
- 作業/短休憩/長休憩の自動遷移
- 4回作業完了ごとの長休憩ルール
- 当日完了ポモドーロ数の集計
- 当日集中時間（秒→時間表示）の集計
- 当日進捗カード表示（完了数・集中時間）
- localStorageへの当日統計保存
- ページ再読み込み時の状態復元（少なくとも当日統計）
- 日付切り替わり時の当日データリセット
- タブ非アクティブ時の時間ずれを抑える実装（終了時刻差分計算）
- モバイル幅でも崩れにくいレスポンシブUI

## 2. 初期リリースであると実用性が上がる機能（準必須）

- 実行中タイマーの復元（再読み込み後も継続計算）
- モードごとの配色切り替え
- セッション完了時の通知（画面内表示または音）
- 作業・休憩時間設定の保存（localStorage）

### 2.1 カスタマイズ性拡張（継続率向上を狙う設定機能）

ユーザーの好みに合わせて挙動と見た目を選べるようにする。継続率や使用頻度への影響を将来的にABテストで測定することを想定する。

- 作業時間の選択: 25分固定から 15 / 25 / 35 / 45 分の中から選択可能にする
- 短休憩時間の選択: 短休憩を 5 / 10 / 15 分の中から選択可能にする（長休憩は現状固定）
- テーマ切替: ダーク / ライト / フォーカス（ミニマル）の3種から切り替え可能にする
- サウンド設定: 開始音 / 終了音 / tick 音をそれぞれ個別に ON / OFF 切り替え可能にする
- 設定値は localStorage に保存し、再読み込み後も維持する

参考: Focus Booster, Pomotodo などの既存タイマーアプリの設定UIを参考にする。

## 3. 将来拡張（後続フェーズ）

- 設定API（取得・更新）
- 日次統計API
- 履歴API
- SQLite永続化（統計・履歴・設定）
- 履歴一覧画面
- 分析画面（週次/月次の可視化）

## 4. 実装順の推奨

1. 最小タイマー（表示、開始/停止/リセット、25分動作）
2. モード遷移（作業・短休憩・長休憩、4回ルール）
3. 当日統計（完了数・集中時間、UI反映）
4. localStorage復元（日次リセット含む）
5. 通知・設定・将来APIへの拡張
